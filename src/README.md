# 250221 과제

### 과제 수행 결과
~~```"test문자001122334455문.자,특수기호##!"```~~
<br> → ***"1,122,334,455"***
<br>

---
### 풀이 과정 (두 가지)
- const text = "test문자001122334455문.자,특수기호##!"
    - 사전에 text 준비. (숫자, 문자, 특수기호 모두 입력 가능하다는 가정.)

---

첫번째 풀이 : ```.toLocaleString()```

1. let num = Number(text.replaceAll(/[^0-9]/g, ""))
    + 정규표현식으로 text에서 숫자만 추출합니다. 
    <br> 3번에서 사용할 ```.toLocaleString()```는 number 타입만 가능하기 때문.
    + ***.replaceAll(/[^0-9]/g, "")*** 
    <br> 숫자를 남기고 나머지를 ""(공백)으로 replace합니다.
    <br> - 풀이: ```^0-9``` **숫자가 아닌** 모든 문자 선택 (0-9로 모든 숫자를 선택하고, ^로  ) → ```g``` 전체를 검색합니다. 

2. let answer = num.toLocaleString('ko-KR')
    + 숫자, 날짜를 문자열로 표기.
    + 천 단위로 반점(```,```)을 찍는 표기법이 필요하므로 'ko-KR'를 파라미터로 지정.

3. return answer;
    + 결과를 반환하고 종료.

--- 
두번째 풀이 : 정규표현식

2. let num = text.replaceAll(/[^0-9]/g, "")
    + 위와 동일. (정규표현식으로 text에서 숫자만 추출합니다. ) 
    + !! 단, ```Number()``` 과정을 생략해서 문자열 형태를 유지합니다.

3. let answer = num.replace(/\B(?=(\d{3})+(?!\d))/g, ",");
    + 정규표현식을 이용해 숫자 세 자리마다 콤마를 찍습니다. 
     → 숫자가 세 번 반복되는 위치에 콤마를 찍는다.
    + 풀이
    <br> ```\B(조건)``` : 처음과 끝을 제외하고, 조건*에 만족하는 위치의 앞자리를 선택한다. (*조건: ```(?=(\d{3})+(?!\d))```)
    <br> ```(x)+(?y)``` 형태의 경우, 'x조건'와 'x조건 뒤 y조건' 둘 다 부합해야 한다.
    <br> ```\d{3}``` : 숫자 세 자리. (```+``` 반복.)
    <br> ```x+(?!\d)``` : x의 뒤가 숫자가 아니어야 함. (추가적으로 숫자가 있을 경우 콤마 생략.)
    + → 숫자 세 자리가 끝나는 지점을 선택해 콤마를 삽입한다.

4. return answer;
    + 결과를 반환하고 종료.
